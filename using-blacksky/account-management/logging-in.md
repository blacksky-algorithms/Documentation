# Logging in

To login to your account:

1. Visit[ blacksky.community](https://blacksky.community/)
2. Select ‘Sign in’
3. Make sure your ‘hosting provider’ is set to the correct one.&#x20;
4. If you have a Blacksky account, this will be the default. If you are using Bluesky or another server you can still login with our app but you’ll need to edit the hosting provider accordingly.
5. Input your username
6. Enter your password.&#x20;
7. If you’ve forgotten your password, you can select the ‘Forgot?’ button to reset it.
